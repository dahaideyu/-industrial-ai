# 03. 系统首页提供知识库分析报告

## 需求概述

在系统首页（Dashboard）直接呈现知识库的分析报告，包括知识库入口、报告嵌入、质量/覆盖度统计以及 AI 分析结果。让运维和业务人员进入系统第一眼就能掌握知识库健康状况，不必再单独跳页。

> 用户此前反馈：基本完成，待用户最终确认验收。
