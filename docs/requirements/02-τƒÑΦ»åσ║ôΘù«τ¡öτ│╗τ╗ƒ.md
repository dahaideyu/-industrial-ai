# 02. 知识库问答系统

## 需求概述

提供基于知识库的智能问答能力。用户在问答页面输入问题后，AI 自动选择合适的知识库进行检索增强（RAG），并将命中的文档以引用方式高亮定位、预览、下载。系统需要支持多轮对话与上下文记忆。

> 当前实际状态：**代码已基本开发完成，但前端一打开就报错，功能暂不可用**（见下方已知问题）。
