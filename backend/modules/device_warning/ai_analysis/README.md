# 工厂设备AI分析系统

> 基于设备报警信息和历史数据的智能分析平台

---

## 一、系统概述

本系统针对工厂球磨机、合膏机等设备，提供基于AI的实时监控、异常检测、故障预测和能耗优化分析能力。

### 数据来源

所有数据来自 **TimescaleDB (PostgreSQL)** 数据库。

> **重要说明**：当前数据库存储的是设备报警状态数据（Alarm1=52个点位的开关量0/1），而非连续参数数据（温度、压力、功率等）。分析模块需要根据实际数据情况进行适配。

#### 数据库配置 (环境变量)

| 环境变量 | 说明 | 默认值 |
|---------|------|-------|
| `POSTGRES_HOST` | 主数据库地址 | CHANGE_ME |
| `POSTGRES_FALLBACK_HOST` | 备用数据库地址 | CHANGE_ME |
| `POSTGRES_PORT` | 端口 | 5432 |
| `POSTGRES_USER` | 用户名 | postgres |
| `POSTGRES_PASSWORD` | 密码 | (见 .env 文件) |

#### 数据库表结构

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `device_info` | 设备信息 | device_id (SERIAL), device_name |
| `point_info` | 点位定义 | point_id, point_name, belong_devide, remark |
| `device_alarm_info` | 报警数据 | device_id, point_id, point_value (0/1), point_time, device_status, raw_json |

#### 设备与点位

| 设备ID | 设备名称 | 点位数 |
|--------|---------|-------|
| 102000018415 | 正1#金帆球磨机 | 52 |
| 102000000996 | 正2#衡远合膏机 | 37 |

### 可用分析能力

基于当前报警数据（Alarm1-52二进制状态），可实现以下分析：

| 分析类型 | 说明 | 数据来源 |
|---------|------|---------|
| 报警统计 | 统计各报警触发频率、持续时间 | Alarm1-52 |
| 设备可用率 | 基于device_status计算设备在线率 | device_status |
| 报警趋势分析 | 基于历史报警模式分析趋势 | Alarm历史 |
| 设备健康评估 | 基于报警活跃度评估 | Alarm活跃度 |

### 数据存储现状

| 数据类型 | 存储内容 | 数值范围 |
|---------|---------|---------|
| 报警状态 | Alarm1-52 开关量 | 0 (正常) / 1 (报警) |
| 设备状态 | 运行/停机 | online/offline |
| 时间戳 | 记录时间 | datetime |

### 扩展需求

如需以下连续参数分析，需扩展数据采集：

| 参数类型 | 需要的采集数据 |
|---------|---------------|
| 温度分析 | 前段/中段/后段温度、铅粉温度 |
| 压力分析 | 正压风压、负压风压 |
| 功率分析 | 主机功率、负载率 |
| 压差分析 | 布袋压差、过滤器压差 |
| 物料分析 | 铅粒仓重量 |

> **扩展数据采集方式**：
> - 模拟量传感器（4-20mA/0-10V）
> - Modbus/TCP 采集数据
> - OPC UA 数据源
> - MQTT 实时数据流

## 二、分析功能模块

### 模块1：异常检测与报警预警

**功能描述**：实时检测设备运行参数异常，预测即将触发的报警。

#### 可检测的异常类型

| 异常类型 | 说明 | 检测方法 |
|---------|------|---------|
| 越限异常 | 参数超过报警上下限 | 阈值比较 |
| 趋势漂移 | 参数缓慢偏离正常范围 | 移动平均分析 |
| 突变异常 | 参数短时间内剧烈变化 | 变化率检测 (>15%) |
| 数据卡死 | 传感器数据长时间不变 | 连续值重复检测 |
| 模式异常 | 多参数组合异常 | 关联规则分析 |

#### 可预警的报警类型

| 报警类别 | 具体报警 |
|---------|---------|
| 风压报警 | 负风风压上/下限、正风风压上/下限、负风压力低 |
| 温度报警 | 前温/中温/后温上下限、布袋温上限 |
| 功率报警 | 电机功率上/下限 |
| 压差报警 | 布袋压差、滤筒压差、过滤器压差 |

#### 输出内容

- 异常点列表（时间、参数、类型、严重程度）
- 报警预测（预测报警、概率、预计时间、建议措施）
- 严重程度统计（低/中/高/严重）

---

### 模块2：设备健康看板

**功能描述**：综合评估设备整体健康状态，输出0-100分的健康指数。

#### 健康评估维度

| 参数 | 权重 | 最优运行区间 | 报警阈值 |
|-----|------|-------------|---------|
| 主机功率 | 20% | 100-105 kW | 80-110 kW |
| 中段温度 | 12% | 205-215 ℃ | 150-230 ℃ |
| 后段温度 | 12% | 205-215 ℃ | 150-230 ℃ |
| 前段温度 | 12% | 205-215 ℃ | 150-230 ℃ |
| 负压风压 | 10% | 210-225 | 150-250 |
| 正压风压 | 10% | 510-530 | 400-550 |
| 铅粉温度 | 8% | 105-112 ℃ | 80-120 ℃ |
| 布袋压差 | 6% | 50-70 | 30-80 |
| 过滤器压差 | 6% | 80-88 | 60-100 |
| 铅粒仓重量 | 4% | 20000-35000 kg | 10000-40000 kg |

#### 健康状态分级

| 状态 | 分数范围 | 说明 |
|-----|---------|------|
| 优秀 | 90-100 | 设备运行状态极佳 |
| 良好 | 75-89 | 设备运行正常 |
| 一般 | 60-74 | 需要关注，建议检查 |
| 警告 | 40-59 | 存在问题，建议尽快处理 |
| 危险 | 0-39 | 严重问题，需立即处理 |

#### 输出内容

- 综合健康指数 (0-100)
- 各参数健康分数和趋势
- 主要风险因素
- 针对性维护建议

---

### 模块3：故障预测

**功能描述**：基于参数变化模式识别潜在故障风险，预测故障发生时间。

#### 可预测的故障类型

| 故障类型 | 相关参数 | 典型前兆 |
|---------|---------|---------|
| 热管理故障 | 前/中/后段温度、铅粉温度 | 温度持续上升、温差异常、温度波动 |
| 压力系统故障 | 正压风压、负压风压 | 风压失衡、负压过低、正压过高 |
| 机械故障 | 主机功率 | 功率波动大、功率异常升高/降低 |
| 过滤系统故障 | 布袋压差、过滤器压差 | 压差持续上升、压差过高 |
| 物料系统故障 | 铅粒仓重量 | 物料消耗异常、物料卡料 |

#### 耗材寿命预测

| 耗材 | 预测依据 | 预警阈值 |
|-----|---------|---------|
| 布袋 | 布袋压差上升趋势 | 压差达到80 |
| 过滤器 | 过滤器压差上升趋势 | 压差达到100 |

#### 输出内容

- 故障风险列表（类型、概率、严重程度、预计时间）
- 预警信号说明
- 预防性维护建议
- 耗材剩余寿命估计

---

### 模块4：能耗优化分析

**功能描述**：分析设备能耗特征，识别节能潜力，提供优化建议。

#### 能耗分析指标

| 指标 | 说明 |
|-----|------|
| 平均功率 | 统计周期内的平均功率消耗 |
| 功率波动 | 功率标准差，反映运行稳定性 |
| 总能耗 | 累计电能消耗 (kWh) |
| 能效评分 | 综合能效指数 (0-100) |
| 空载时间比例 | 功率<20kW的时间占比 |
| 过载时间比例 | 功率>110kW的时间占比 |

#### 优化分析维度

| 分析维度 | 检测条件 | 优化方向 |
|---------|---------|---------|
| 空载优化 | 空载时间>5% | 优化生产排程，减少空转 |
| 负载均衡 | 过载时间>2% | 分散高峰负载，优化进料 |
| 稳定运行 | 功率标准差>5kW | 优化PID参数，检查机械磨损 |
| 温度协调 | 各段温差>5℃ | 优化加热/冷却系统 |
| 风压平衡 | 正负压比偏离2.0-2.8 | 调整风机频率，检查管道 |
| 压差维护 | 压差持续上升 | 清理或更换滤材 |

#### 最佳运行时段识别

- 按小时统计运行效率
- 识别高效运行时间窗口
- 分析运行特征（夜班/白班效率差异）

#### 输出内容

- 能耗概况统计
- 能效评分
- 最佳运行时段
- 优化建议（按优先级排序）
- 节能潜力估算（kWh/天、月度节省电费）

## 三、使用方法

### 运行完整分析

```bash
python modules/device_warning/ai_analysis/main.py
```

### 运行单个模块

```bash
# 异常检测
python modules/device_warning/ai_analysis/main.py --module anomaly

# 健康看板
python modules/device_warning/ai_analysis/main.py --module health

# 故障预测
python modules/device_warning/ai_analysis/main.py --module fault

# 能耗分析
python modules/device_warning/ai_analysis/main.py --module energy
```

### 输出JSON格式

```bash
python modules/device_warning/ai_analysis/main.py --json --output result.json
```

## 三、定时调度配置

> 独立调度脚本 scheduler.py 已移除（2026-07）。定时任务统一由「系统管理 → 任务管理」
> （`routes/system_jobs.py` + `core/scheduler.py`）调度；本模块的分析能力仍可通过
> `/api/device_analysis`（设备诊断页）按需调用，或被预测性维护报告集成调用。

### Job 运行记录表 (analysis_job_run)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL | 主键 |
| job_name | VARCHAR(50) | 任务名称 |
| status | VARCHAR(20) | pending/running/success/failed |
| start_time | TIMESTAMP | 开始时间 |
| end_time | TIMESTAMP | 结束时间 |
| duration_seconds | INTEGER | 运行时长(秒) |
| result_summary | JSONB | 结果摘要 |
| error_message | TEXT | 错误信息 |

### Job 日志表 (analysis_job_log)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL | 主键 |
| job_run_id | INTEGER | 关联 job_run |
| log_level | VARCHAR(20) | info/warning/error |
| message | TEXT | 日志消息 |
| details | JSONB | 详细信息 |

### 查询 Job 状态

```python
from modules.device_warning.ai_analysis.postgres_loader import PostgresDB

db = PostgresDB()
db.connect_with_fallback()

# 查询所有 Job 状态
df = db.get_job_status("health_check")
print(df)

# 查询某个 Job 的日志
df = db.get_job_logs(job_run_id=1)
print(df)

db.close()
```

## 五、报警集成

### 支持的报警方式

系统支持通过回调函数对接各类报警通道：

- 钉钉机器人
- 企业微信
- 短信通知
- 邮件通知
- 自定义HTTP接口

### 报警触发条件

| 报警类型 | 触发条件 | 严重级别 |
|---------|---------|---------|
| 异常报警 | 检测到高/严重级别异常 | warning |
| 预测报警 | 报警预测概率>70% | warning |
| 健康报警 | 健康指数<60 | critical |
| 健康提醒 | 健康指数<75 | warning |
| 故障预警 | 故障概率>60%且严重程度>=中等 | warning |
| 能效提醒 | 能效评分<70 | info |
